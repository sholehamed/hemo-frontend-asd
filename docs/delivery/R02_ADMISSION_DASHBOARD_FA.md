# R02 — داشبورد پذیرش
- مبنا PR18 ادغام‌شده 36fa69e6 با 102/102 تست. داشبورد موجود /admission و مسیر اختصاصی /admission/dashboard با Guard اصلی فعال شدند. alias برای حفظ منوی قدیمی شرکت و امکان Seed مستقل است؛ مجوز آن در PR بک‌اند جداگانه اعمال می‌شود.
- Capability محلی: stats و list مستقل؛ عدم دسترسی یا خطای یکی مانع نمایش داده مجاز دیگری نیست. ثبت سریع فقط با create/find/detail، لینک بررسی فقط با list/detail/reviews و history در صورت نیاز. فرم ثبت سریع هنگام refresh بسته نمی‌شود چون refresh در زمان باز بودن آن غیرفعال است.
- جستجو و درخواست‌های دیرهنگام تحت scope صفحه و sequence هستند. تغییر نشست یا خروج، پاسخ قبلی را نامعتبر می‌کند. هیچ grant یا تصمیم بالینی در UI صادر نمی‌شود.
- راهنمای کاربر: مدیر آمار فقط شاخص‌ها و گزارش مجاز، نقش دارای list فهرست و جستجو، و نقش پذیرش دارای مجوز ثبت سریع را می‌بیند. ورود به هر مقصد با Guard مستقل کنترل می‌شود.
- چهار آزمون HTTP/رندر و یک آزمون Guard اضافه شده‌اند. CI جدید هنوز تایید نشده. هیچ حساب، migration، تغییر bootstrap یا auth عمومی وجود ندارد. تست واقعی بک‌اند و چاپگر و سایر ماژول‌ها باقی است.
