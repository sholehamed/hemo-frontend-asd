# R02 — ارتباط بین‌ماژولی پذیرش تا تزریق
مبنا: Integration 18771e5d؛ PR27 ادغام شده، backend main 7897735b.
## راهنمای کاربر
در جزئیات پرونده پذیرش، درخواست خون، واحد بانک خون و حواله، دکمه «مسیرهای مرتبط» را بزنید. فقط مقصدهایی که بررسی دسترسی صفحه آنها پاسخ مثبت داده است نمایش داده می‌شوند. پس از تغییر نقش یا پرونده، دسترسی باید دوباره بررسی شود.
- پذیرش: فهرست درخواست‌ها و سوابق تزریق همان پرونده؛ برای پذیرش فعال، فرم ثبت درخواست پرستار یا پزشک.
- درخواست: پرونده پذیرش، تاریخچه آزمایش‌ها، حواله‌ها؛ برای درخواست در صف بانک، Crossmatch، صف ذوب و صف بررسی صدور.
- واحد بانک: برای واحد دارای درخواست مرتبط، جزئیات درخواست و سوابق حواله‌های همان درخواست؛ برای واحد آماده، غیرمنقضی و بدون توقف فنی، صف بررسی صدور درخواست. این لینک به معنای مجوز بالینی صدور نیست؛ سرور کاندیداها را دوباره کنترل می‌کند.
- حواله: پذیرش، درخواست عمومی یا بانک، گردش واحد و سوابق همان درخواست.
## توسعه‌دهنده
HemoRelatedLinksComponent از HemoPageScope و HemoCompanyHttp صفحه استفاده می‌کند. مسیر دقیق ثبت‌شده در منو (شامل :guid) به CheckPagePermission ارسال می‌شود؛ GUID و فیلتر در لینک محلی باقی می‌مانند. بررسی هنگام درخواست کاربر انجام می‌شود تا در هر بار باز شدن پرونده چندین فراخوانی اضافه ایجاد نشود. هیچ تغییر در sessionStorage یا مجوزهای نقش ایجاد نمی‌شود. مقصد همچنان Guard، قابلیت سرور و کنترل رکورد/مرکز را اجرا می‌کند؛ بررسی منو جایگزین مجوز API نیست.
در فرم درخواست، تغییر query پذیرش در مسیر استفاده‌شده مجدداً فرم را مقداردهی می‌کند تا اطلاعات بالینی یا شناسه درخواست قبلی منتقل نشود؛ پیش‌نویس ذخیره‌نشده پاک می‌شود. پاسخ قدیمی نادیده گرفته می‌شود.
## تست و محدودیت
چهار تست component/HTTP مربوط به مسیرهای مرتبط و یک تست استفاده مجدد مسیر فرم درخواست. CI هنوز تأیید نشده است. Seed، حساب یا Migration تازه نیاز نیست؛ گزینه‌های فعال‌سازی قبلی R02 باید برقرار باشند. ارتباط با هموویژیلانس پس از اتصال آن ماژول تکمیل می‌شود. UAT واقعی باقی است.
