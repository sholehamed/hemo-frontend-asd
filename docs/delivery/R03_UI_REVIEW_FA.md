# R03-05 — بازبینی رابط کاربری HEMO
مبنای تأیید شده: backend main 82864ea9 (PR #34؛ CI 46081842421 و 46081842380 سبز)، frontend main d513ef5d. مرورگر واقعی R03-04 برای مدیر آمار، پذیرش و مشاهده‌گر موفق بود.
## یافته‌های بررسی کد و اصلاح
- Angular 19 از src/styles.scss استفاده می‌کند و src/styles.css تاریخی شامل استایل‌های HEMO در angular.json فعال نیست. به‌جای وارد کردن آن فایل با استایل‌های global و تم دوم Material، یک stylesheet SCSS اختصاصی به Build اضافه شده است.
- فقط wrapper موجود RouterOutlet در AppLayout، براساس routeConfig.path فعال، کلاس hemo-page می‌گیرد. مسیرهای admission و hemo هدف هستند؛ شرکت، Login و صفحات عمومی خارج از scope می‌مانند. Guard، احراز هویت، منو، API، فرم‌ها و قواعد گردش تغییر نکرده‌اند.
- فرم‌ها شبکه واکنش‌گرا دارند، ورودی‌ها و حالت disabled مشخص‌اند، دکمه‌ها focus قابل مشاهده و در موبایل حداقل 44px ارتفاع دارند، جدول‌ها داخل wrapper اسکرول می‌خورند، پنل‌ها/شاخص‌ها/هشدارها و شناسه‌های LTR تعریف می‌شوند. پالت اصلی با تم آبی شرکت هم‌راستا است. برای پوسته dark از متغیرهای scoped و برای مچ‌بند از زمینه سفید استفاده شده است.
- lang صفحه fa و اشتباه viewport initial-scale=1.o به 1.0 اصلاح شدند. قواعد print فقط هنگام وجود print-target در صفحه HEMO سایر محتوا را مخفی می‌کنند؛ چاپگر و اسکنر واقعی هنوز آزموده نشده‌اند.
## اعتبارسنجی
Workflow HEMO R03 UI review، کد همین PR را بدون Mock و با backend main ثابت 82864ea9، SQL ایزوله، JWT آزمایشی، و پورت 18002 اجرا می‌کند. فقط API URL در checkout موقت CI جایگزین می‌شود. runner قبلی R03-04 ابتدا بدون تغییر اجرا می‌شود؛ سپس سناریوهای عرض 390 و 1440، RTL، شبکه فرم، محتوای داشبورد، رنگ dark، اسکرول جدول، چاپ مچ‌بند و عدم scope در صفحه اصلی شرکت اجرا می‌شوند. تصاویر مصنوعی در صورت موفقیت به artifact با نگهداری هفت روز منتقل می‌شوند. CI معمولی Angular و baseline تاریخی نیز باید موفق بمانند.
## محدوده
هنوز نتیجه CI جدید و بررسی بصری تصاویر تأیید نشده است. بازبینی کد به کلاس‌های مشترک HEMO مربوط است؛ آزمون مرورگر نماینده تمام 62 صفحه، دستگاه‌های واقعی، دسترسی‌پذیری کامل، چاپ واقعی یا ورود/captcha/OTP/refresh شرکت نیست. هیچ کاربر، Seed، Migration یا تغییر عملیاتی بک‌اند جدید وجود ندارد. پس از merge فرانت باید SHA ثابت در CI مرورگر بک‌اند به نسخه جدید منتقل شود. R03-06 نیازمند محیط آزمایشی مجاز شرکت و بررسی انسانی پذیرش است.
