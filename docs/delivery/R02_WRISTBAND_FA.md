# R02 — احیای بارکد مچ‌بند در Angular19
- JsBarcode 3.11.6 همان نسخه snapshot ST09 با lock تأییدشده (CI 46059513576 و 46060986914) است. فقط این dependency بدون وابستگی جانبی به manifest و lock Angular19 اضافه شد؛ مقایسه همه 1322 ورودی قبلی lock بدون تغییر بود (1323 پس از اضافه شدن).
- استفاده از import محلی به جای متغیر global؛ بدون تغییر angular.json، bootstrap، script سراسری، یا سایر کتابخانه‌ها. declaration محدود به SVG/CODE128.
- مقدار واقعی wristbandCode صادرشده سرور بدون بازسازی، تولید شناسه در UI یا تغییر کاراکتر استفاده می‌شود. هنگام تغییر بیمار، کد خالی/نامعتبر یا scope نامعتبر، چاپ غیرفعال است و SVG قبلی پاک می‌شود. چاپ فقط پس از تولید موفق برای GUID و code فعلی اجازه دارد.
- سه تست Karma برای SVG واقعی، تغییر بیمار، نبود کد، نامعتبر بودن و scope؛ npm ci و تست/Build جدید هنوز تایید نشده‌اند. این تست خوانایی واقعی اسکنر، ابعاد فیزیکی و قالب چاپگر نیست. چاپ window.print فعلی حفظ شد؛ قالب چاپ اختصاصی و UAT چاپ باید قبل از بهره‌برداری بالینی تایید شوند.
- صفحات create/detail هنوز به routing اصلی وصل نشده‌اند؛ احیای وابستگی و آزمون مستقل اولین گام است. هیچ تغییر AuthService، Guard، Seed یا حساب و migration وجود ندارد.
