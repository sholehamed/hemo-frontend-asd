# R02 — صفحات خواندنی تحویل و تزریق
مبنا: Integration 86bcb416؛ PR25 ادغام شده.
## راهنمای کاربر
- داشبورد تحویل و تزریق: آمار مرکز جاری؛ فهرست اخیر فقط برای نقش دارای مجوز فهرست. خطای فهرست مستقل از آمار نمایش داده می‌شود.
- کارتابل حواله‌ها و سوابق: جستجوی بیمار، واحد، شماره حواله، بخش، وضعیت و تاریخ شمسی؛ چاپ و CSV صفحه جاری.
- کارتابل علائم حیاتی: نقش دارای مجوز ثبت علائم؛ وضعیت ثابت Active. کارتابل پزشک: نقش دارای مجوز یادداشت پزشک؛ وضعیت ثابت Active.
- مرجوعی: نقش دارای یکی از مجوزهای ارسال، دریافت یا امحای مرجوعی؛ وضعیت ثابت ReturnQueue.
- صفحات فقط خواندنی هستند. جزئیات، صدور، دریافت، تطبیق، تزریق و ثبت عملیات در مرحله بعد متصل می‌شوند؛ لینک‌های مربوطه فعلاً مخفی هستند.
## توسعه‌دهنده
TransferDashboardComponent و TransferListComponent موجود حفظ شده‌اند. TransfusionService از HemoCompanyHttp، TransferPageAccess و HemoPageScope در سطح صفحه استفاده می‌کند. شش مسیر تحت Guard شرکت؛ قابلیت‌ها از سرور، پاسخ قدیمی و تغییر نشست کنترل می‌شوند. فیلتر درخواست/پذیرش با تغییر query به‌روز می‌شود؛ خروجی فقط در Scope معتبر.
## تست
۶ تست component/HTTP و ۲ تست Guard. CI و UAT واقعی هنوز تأیید نشده‌اند. تنظیمات Seed متناظر در بک‌اند؛ حساب‌های آزمایشی قبلی و قرارداد API بدون تغییر.
